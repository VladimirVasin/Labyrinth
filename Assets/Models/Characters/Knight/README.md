# Knight Model Folder

Drop the knight character model files here.

Recommended contents:

- `.fbx`, `.obj`, or `.glb` model file
- texture files
- material files, if exported separately
- animation files, if the model has them

Suggested naming:

- `Knight.fbx`
- `Knight_Idle.fbx`
- `Knight_Walk.fbx`
- `Textures/`
